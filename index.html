  2. Gere aqui o arquivo de configuração do armazém e salve-o dentro dessa pasta.
    3. 
              
  3. Dê dois cliques em instalar-agente.bat.
    4. 
            

            

              
              
            

            
O arquivo contém a senha de acesso do computador. Gerar de novo invalida o arquivo anterior — gere uma vez só e, se o download falhar, use "Baixar o mesmo arquivo de novo".
